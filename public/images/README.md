Letakkan foto profil Anda di folder ini dengan nama `profile.jpg`.

- Nama file: profile.jpg
- Format yang direkomendasikan: JPEG atau PNG
- Resolusi: Minimal 800x800 untuk hasil bagus (gambar akan di-crop ke lingkaran)
- Cara mengganti: salin file foto ke `public/images/profile.jpg`

Setelah Anda menaruh file, refresh halaman `public/index.html` di browser.
